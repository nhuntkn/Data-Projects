# Janet's Projects

A collection of hands-on projects to build practical experience in data science and data engineering — spanning ETL pipelines, cloud infrastructure, machine learning, and analytical dashboards.

---

## Projects

### [Australia Road Deaths](Australia-Road-Deaths/) — Data Engineering
An end-to-end data pipeline that ingests Australian road fatalities data from a government source, models it into fact and dimensional tables, orchestrates the ETL flow, and surfaces insights in an interactive dashboard.

**Stack:** Python, SQL, Google Cloud Storage, Mage AI, BigQuery, Looker Studio

### [Transaction Fraud Detection](Transaction-Fraud-Detection/) — Data Science
A machine learning pipeline to detect fraudulent financial transactions in a highly imbalanced dataset (1.71% fraud rate). Covers EDA, feature engineering, and model comparison across Logistic Regression, XGBoost, and LightGBM.

**Stack:** Python, Jupyter Notebooks, XGBoost, LightGBM
